Mesh
A lightweight blockchain wallet, miner, and explorer
Mesh is a lightweight peer-to-peer blockchain wallet with mining, transactions, on-chain messages, and a built-in block explorer.

About Mesh

Mesh is a small open-source cryptocurrency created by 7xy_ to explore how blockchains work. It started as a Python project and was later rewritten in JavaScript as an app, making it easier to install, run, and use across different devices.

How Mesh Works

Mesh is a peer-to-peer cryptocurrency. Each computer running the software keeps a copy of the blockchain, while independently verifying new transactions and blocks.

Mining blocks requires the computer to repeatedly test different values until it finds one that produces a valid block. When a miner succeeds, they receive the block reward and share the new block with the rest of the network. This process requires computational work, which makes it difficult to alter confirmed transactions. A transaction becomes more secure as additional blocks are mined after it.
