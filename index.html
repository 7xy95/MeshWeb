Mesh
A lightweight blockchain wallet, miner, and explorer
Mesh is a lightweight peer-to-peer blockchain wallet with mining, transactions, on-chain messages, and a built-in block explorer.

About Mesh

Mesh is a small cryptocurrency, designed by 7xy_ with the goal of understanding how a blockchain works. It was originally developed in Python, however later was re-written in JavaScript as an app due to Python not being accessible to everyone.
