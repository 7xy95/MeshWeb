# Mesh Web

Mesh Web is a web browser with a decentralised DNS. Domains are registered with proof of work, and registrations are shared and maintained by all nodes.

## Features

- Register .mesh domains through mining.
- Change the endpoint using private key of most active registration.
- Tor service endpoints are supported.
- View and open .mesh domains in Mesh Web.

## Getting Started

Mesh Web can be downloaded from the [Releases](https://github.com/7xy95/MeshWeb/releases) page.

## Protocol

More information about the network and DNS system is available in the [protocol documentation](https://meshcoin.org/webDocs/).
